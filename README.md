# Sweet Sweet Home

네 환자의 상담 기록을 읽고, 처방전을 작성하고, 전화 상담을 마치면 숨겨진 폴더가 열리는 데스크톱 미스터리 게임입니다. 작업 기록에서 환자를 선택해 이야기를 시작할 수 있습니다.

打开房间里的电脑即可开始。四位患者的咨询、处方和电话回访全部完成后，隐藏文件夹会解锁，信件会根据处方选择进入两种结局之一。

## 실행 / 本地运行

在项目目录使用 Node.js 和 npm。

```sh
npm ci
npm run dev
```

用 Chrome 打开终端显示的本地地址。使用 `npm run build` 生成部署文件，产物位于 `dist/`。使用 `node --test tests/progress.test.mjs` 运行玩法回归测试。

## 试玩一位患者

1. 打开电脑，在「工作记录」选择患者 A。读完「镜子」「控制」「羞耻」三段回忆，每段最后点击「记录回忆」。
2. 打开桌面的「处方单」，选择患者 A。填写一项主要问题、两项干预方式和一项咨询建议。右侧纸张会即时更新。
3. 点击「开具处方」，查看已盖章的处方单。点击「电话回访」，读至最后并结束通话。
4. 回到「处方单」确认患者状态为「已完成」。已开具的处方可以重看，工作记录里也可以重读回访。
5. 完成其余三位患者后，在「隐藏文件夹」打开「没寄出的信」。

单击桌面图标或 Dock 可以打开应用。拖动标题栏可以移动窗口。桌面「设置」可切换中韩语言、存读档和关闭电源。剧情中的顶部「系统设置」可存档、读档或返回桌面。「iPod」负责音乐与音效音量。

自动进度和手动存档保存在当前浏览器。要重选已经开具的处方，请先读回开具前的手动存档。旧版 A、B 的咨询完成记录会沿用，历史电话和结局须按新的处方与回访流程重新完成。

## 快速验证结局

运行 `npm run dev` 后，在桌面的「设置」展开「开发调试」。可以标记四位患者已完成咨询、查看内部处方判定，或重置测试进度。加载任一种结局的测试状态后，进入「隐藏文件夹」→「没寄出的信」→「展开信纸」。加载测试状态会替换当前自动进度，手动存档可用于回到测试前的状态。部署版本不包含调试面板。

## 替换内容

| 内容 | 文件 |
| --- | --- |
| 患者资料、咨询摘要、回访记录摘要 | `src/patients.ts` 的 `patientFiles` |
| 处方候选项和内部答案 | `src/patients.ts` 中各患者的 `options` 与 `answer` |
| 咨询回忆、电话回访、两种结局 | `src/story.ts` 的 `memories`、`calls`、`endings` |
| 处方工作台、桌面图标、样式 | `src/prescription.tsx`、`src/visuals.tsx`、`src/playtest.css` |

每条内容可填写中韩两种文案。修改候选项时请保留稳定的选项 ID，并让 `answer` 引用相应 ID。部署配置位于 `.openai/hosting.json`。
