# Sweet Sweet Home

로컬에서 실행하는 복고풍 데스크톱 탐색 데모입니다. 시작 화면의 노트북을 누른 뒤 데스크톱의 `환자 기록`에서 환자 01/02를 열고 상담 기록의 키워드로 회상 장면을 탐색하세요. 필요한 단서를 모두 살펴본 다음 전화 회상을 완료하면 숨겨진 폴더가 열립니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 여세요. 창은 제목 표시줄을 드래그해 이동하고, 빨강/노랑/초록 점으로 닫기·최소화·이동할 수 있습니다. 설정에서 한국어/중국어 전환, 수동 저장/불러오기, 효과음 설정과 진행 초기화를 할 수 있습니다. 메모, 영상 목록, 지뢰찾기, 계산기도 포함됩니다. 진행 및 기본 설정은 브라우저의 localStorage에 저장됩니다.

## 在线体验与新版界面

线上入口：https://sweet-sweet-home-demo.frostycloud18.chatgpt.site

界面采用 SVG / CSS 绘制的蓝灰复古电脑风格。点击房间内的电脑进入桌面，点击蛋糕可查看短提示；设置中的「전원 끄기 / 关闭电源」返回房间并保留探索进度。窗口支持拖动、关闭、最小化恢复和放大。桌面图标双击打开，Dock 单击打开；键盘 Enter 打开选中的图标，Escape 关闭当前窗口。

构建：`npm run build`。部署身份保存在 `.openai/hosting.json`，后续发布复用当前站点。
