# Sweet Sweet Home

두 환자의 상담 기록을 읽으며 기억을 탐색하는 데스크톱 미스터리 게임의 프롤로그입니다. 방에서는 케이크를 살펴보거나 컴퓨터를 켤 수 있습니다. 데스크톱의 업무 기록에서 환자를 선택하고 세 개의 기억을 끝까지 읽으면 전화 회상이 열립니다. 두 통의 통화를 마치면 숨겨진 폴더에서 개인 메모와 편지를 읽을 수 있습니다.

桌面推理游戏的序章。点击房间里的蛋糕可发现线索，点击电脑可进入桌面。打开工作记录，读完每位患者的三段回忆后完成电话回访。两通电话结束后，隐藏文件夹会解锁。

## 실행 / 本地运行

```sh
npm ci
npm run dev
```

生产构建使用 `npm run build`，构建产物位于 `dist/`。

## 操作

- 单击桌面图标或 Dock 打开应用。拖动标题栏移动窗口，可用窗口按钮关闭、最小化或放大。
- 桌面「设置」提供中韩切换和手动存读档。探索进度会自动保存在当前浏览器。
- 视觉小说占用整个窗口。顶部「系统设置」可以保存或读取当前对白、继续阅读或退出到桌面。
- 桌面「iPod」可播放临时背景音乐并分别调整音乐和音效的音量。
- 桌面「相册」需要密码解锁，关闭窗口后会重新上锁。
- 「关闭电源」会回到初始房间。重新开机时，玩家可以继续探索。

部署配置位于 `.openai/hosting.json`。
